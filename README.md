# IoT--alapu-ESP32-CAM-keprogzito-es-e-mail-tovabbito-rendszer-tervezese-es-megvalositasa

Feladatunk egy IoT-alapú, ESP32-CAM mikrokontrollerre épülő képrögzítő és e-mail továbbító felügyeleti rendszer megvalósítása volt. A kifejlesztett eszköz fizikai nyomógomb lenyomására – amely a későbbiekben mozgásérzékelőre is cserélhető – automatikusan fényképet készít, majd azt e-mailben továbbítja a megadott fiókba.
